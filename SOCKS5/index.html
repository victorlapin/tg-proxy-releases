    Режим SOCKS5

    Приложение поддерживает два режима подключения к Telegram. Понимание разницы между ними помогает выбрать правильный для вашей сети.

    Два режима

    MTProto (по умолчанию) — полноценный прокси-движок с маскировкой трафика и обходом блокировок. Это то, что включается после онбординга и работает на большинстве сетей, включая те, где Telegram заблокирован.

    SOCKS5 (Legacy) — упрощённый режим: прямой TCP-мост до серверов Telegram, без маскировки и без обхода блокировок. Быстрее на чистых сетях, но бесполезен там, где трафик фильтруется.

    Чем отличаются

    MTProto SOCKS5
    Маскировка трафика Да (FakeTLS — трафик выглядит как обычный HTTPS) Нет
    Обход блокировок (DPI) Да (через Cloudflare) Нет
    Профили Работают (FakeTLS, CF-воркеры, автопереключение) Не применяются
    Автопереключение по сети Работает (Wi-Fi ↔ мобильная сеть) Отключено
    DC:IP маппинги Работают Работают (единственная настройка из профиля, которая применяется)
    Скорость на чистой сети Чуть медленнее (маскировка и шифрование) Быстрее (минимум overhead)
    Работает ли там, где Telegram заблокирован Да Нет

    Когда использовать SOCKS5

    • Telegram не заблокирован, но хочется максимальной скорости. Например: домашний Wi-Fi, провайдер не блокирует Telegram.
    • Для диагностики. Если в режиме MTProto что-то не работает, а в SOCKS5 — работает, значит проблема в обходе/маскировке, а не в базовом подключении.

    Когда НЕ использовать SOCKS5

    • Провайдер блокирует Telegram (DPI, фильтрация по SNI, блокировка по IP). SOCKS5 не умеет обходить блокировки — трафик идёт как есть, без маскировки. В этом случае поможет только MTProto.
    • Нужны профили и автопереключение. В режиме SOCKS5 профили не применяются (кроме DC:IP маппингов), автопереключение по сети отключено.

    Переключение режимов

    Откройте Настройки → секция «Режим подключения» → выберите MTProto или SOCKS5.

    При переключении приложение сгенерирует новую ссылку для Telegram. Старую нужно удалить в настройках прокси Telegram и добавить новую — приложение подскажет ссылку при переключении.

    Что сохраняется при переходе

    Настройки профилей (FakeTLS, CF-воркеры, DC:IP маппинги) не удаляются при переходе в SOCKS5 — они просто не применяются, пока вы не вернётесь в MTProto. Это позволяет свободно переключаться между режимами без потери конфигурации.
