    Несколько профилей для разных сетей

    В TG WS Proxy профиль — это «вариант пути до Telegram». Под разными сетями один и тот же путь работает по-разному: домашний провайдер обычно пускает напрямую, а у мобильного оператора часто нужен обход через Cloudflare. Автопереключение между профилями делает это за вас.

    После онбординга у вас уже есть один профиль «Основной» с включённым Cloudflare-обходом — он подходит как «безопасный default», который работает на большинстве сетей. Превратим его в мобильный профиль и добавим к нему второй — для домашнего Wi-Fi без обходов.

    Сценарий

    • Мобильный оператор — нужен Cloudflare.
    • Дом — Wi-Fi, прямое подключение работает быстрее.

    Шаги

    Меню профиля (Настроить / Закрепить / Переименовать / Дублировать / Удалить) открывается как через три точки на чипе, так и долгим тапом по самому чипу — что удобнее.

    1. Переименуйте «Основной» в Мобильный
    2. Меню профиля → Переименовать.

    3. В появившемся диалоге введите Мобильный → подтвердите.

    4. Настройте профиль Мобильный

    5. Меню профиля → Настроить.
    6. Cloudflare-обход: оставьте включённым (был включён после онбординга).
    7. Поле «DC:IP маппинги»: оставьте пустым. Прокси будет использовать встроенные адреса серверов Telegram и при необходимости задействует запасной способ обхода (domain fronting), который работает именно на канонических адресах.
    8. Автопереключение: Мобильная сеть.

    9. Сохранить.

    10. Создайте и настройте второй профиль

    11. Главный экран → + в конце списка профилей (или меню профиля → Дублировать, если хочется начать с готового набора настроек).
    12. В появившемся диалоге введите Дом → подтвердите. Откроется экран редактирования.
    13. Cloudflare-обход: выключите.
    14. Поле «DC:IP маппинги»: нажмите По умолчанию в поле — подставятся адреса 2:149.154.167.220 и 4:149.154.167.220. Прямое подключение к этим адресам на домашнем провайдере работает быстрее всего.
    15. Автопереключение: Wi-Fi.
    16. Сохранить.

    Готово. При переключении телефона между Wi-Fi и мобильной сетью приложение само выберет нужный профиль.

    Как работает автопереключение

    Каждый тип сети (Wi-Fi или Cellular) может быть привязан только к одному профилю — в карточке настройки профиля секция «Автопереключение» не даст выбрать тип, который уже занят другим профилем.

    При смене активной сети приложение находит профиль, привязанный к её типу, и делает его активным. Если ни один профиль не привязан к текущему типу сети, активный профиль не меняется.

    Чтобы временно отключить автопереключение целиком — закрепите любой профиль через пункт Закрепить в меню. До ручного открепления активный профиль не сменится, какая бы сеть ни появилась.

    URL прокси, который Telegram запомнил при онбординге, общий на все профили — добавлять новые подключения в Telegram'е после создания нового профиля не нужно. Сменится только то, как приложение обрабатывает трафик после получения.

    Частые ошибки

    • «После смены сети Telegram молчит ~10 секунд» — это нормально: идёт graceful-rebind на новый профиль. Соединение восстановится.
    • «Хочу один профиль, чтобы прокси никогда не переключался автоматом» — закрепите его иконкой замка. Автопереключение перестанет менять активный профиль до снятия пина.
