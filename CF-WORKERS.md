# Личные Cloudflare-воркеры

Когда встроенный обход через общие домены Cloudflare не справляется —
насыщение лимитов, блокировки со стороны оператора — личный
Cloudflare-воркер даёт собственный канал обхода, который принадлежит
только вам.

## Когда нужен личный воркер

- **Общие домены перестали работать.** Community-домены Cloudflare
  используются всеми пользователями приложения. При большой нагрузке
  Cloudflare вводит лимиты на одновременные WebSocket-соединения, и
  общие домены начинают отдавать ошибку 429.
- **Оператор блокирует общие домены.** Некоторые провайдеры блокируют
  конкретные community-домены, но пропускают `*.workers.dev`.
- **Нужна стабильность.** Личный воркер находится под вашим
  контролем — никто другой его не исчерпает.

## Развёртывание воркера

Подробная инструкция по созданию воркера в панели Cloudflare — в
[документации апстрима](https://github.com/Flowseal/tg-ws-proxy/blob/main/docs/RU/CfWorker.md).
Кратко: бесплатно, не требует покупки домена, работает на бесплатном
тарифе Cloudflare Workers.

После развёртывания вы получите URL вида
`random-name.username.workers.dev` — это и есть адрес воркера.

## Настройка в приложении

1. Откройте **редактирование профиля** (меню профиля → «Настроить»).
2. В поле **«Домены CF-воркеров»** введите адрес вашего воркера
   (`random-name.username.workers.dev`).
3. Если воркеров несколько — каждый с новой строки.
4. Cloudflare-обход должен быть **включён**.
5. Сохраните.

Прокси будет использовать ваш воркер как приоритетный путь обхода.
Общие community-домены остаются как запасные — если воркер недоступен,
прокси переключится на них.

## Проверка

После настройки откройте **«Проверка сети»** (меню на главном экране).
Экран покажет, достижим ли ваш воркер с текущей сети. Зелёный
индикатор — воркер работает, красный — недоступен.

Если воркер работает, но Telegram не загружает фотографии и видео:

- Для аккаунтов без Telegram Premium: откройте редактирование профиля
  → в поле «DC:IP маппинги» оставьте только `4:149.154.167.220` и
  удалите остальные строки.

## Несколько воркеров

Можно развернуть 2-3 воркера на разных аккаунтах Cloudflare и указать
их все в настройках. Прокси выбирает случайный при каждом подключении —
нагрузка распределяется, а при сбое одного остальные продолжают
работать. При повторных ошибках (5xx, 429) проблемный воркер временно
исключается из ротации на 10 минут.

## Community-обход (без личного воркера)

Если личный воркер не нужен, приложение использует встроенный список
общих Cloudflare-доменов. Это работает на большинстве сетей, но
зависит от нагрузки community-пула. Подробнее об этом способе и о
настройке собственного домена через Cloudflare DNS — в
[документации апстрима](https://github.com/Flowseal/tg-ws-proxy/blob/main/docs/RU/CfProxy.md).
